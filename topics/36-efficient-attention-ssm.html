Efficient Attention & State Space Models

Replacing or reshaping self-attention so that sequence models scale sub-quadratically in compute and stop paying a linearly growing memory bill for every token they remember.

Foundation

What Is It?

Self-attention compares every token to every other token, so its compute and activation memory grow quadratically with sequence length. At a few hundred tokens this is irrelevant; at a hundred thousand it dominates everything else in the model. This research area covers the two responses: make attention cheaper while keeping its form, or replace it with a mechanism that carries information forward through a fixed-size recurrent state instead.

There is a second cost that matters more in deployment and gets less attention in papers. During autoregressive generation the model caches the key and value vectors of every previous token, and that KV cache grows linearly with context and batch size. For a long-context model serving many concurrent users, the cache can exceed the size of the model weights themselves, and because generation is memory-bandwidth-bound rather than compute-bound, cache size — not FLOPs — is usually what caps throughput.

Simple Analogy

Attention is like a meeting where every participant must speak to every other participant before any decision is made: perfect information sharing, and utterly unworkable past a few dozen people. A state space model is the opposite arrangement — a single running set of minutes passed down the table, where each person reads it, updates it, and hands it on. The minutes never grow, so a thousand people cost no more per person than ten, but anything not written down is gone.

That contrast is the field's central trade-off. Attention has perfect recall over its context because it keeps everything; recurrent and state-space alternatives have bounded memory and must decide, online and irreversibly, what to keep. Most of the interesting recent work is about narrowing that recall gap without giving up the constant-memory property, and the pragmatic consensus has landed on hybrids that use a small number of full attention layers inside an otherwise recurrent stack.

Motivation

Why It Matters

Context length has become a headline capability, and the cost structure of attention is what stands between a demo at 128K tokens and an economically viable product serving it to thousands of users at once.

  • 📉 Serving economics: Prefill cost scales quadratically with prompt length and decode throughput is limited by KV cache bandwidth, so cache-reduction techniques translate almost directly into higher batch sizes and lower cost per token.
  • 📚 Genuinely long inputs: Whole codebases, legal document sets, long-form video, and genomic sequences run to hundreds of thousands or millions of tokens — lengths where quadratic attention is not merely expensive but infeasible.
  • 📱 On-device deployment: Constant-memory recurrent inference suits phones and embedded hardware, where a KV cache that grows with conversation length is the binding constraint long before compute is.
  • ⚡ Streaming and low latency: State space models process a new token in constant time regardless of history, making them attractive for real-time audio, control, and continuous sensor streams where per-token latency must be bounded.
  • 🔬 An open architectural question: Whether attention is fundamental or merely a very effective heuristic is still unsettled, and it is one of the few places left where a genuinely new sequence-modelling primitive could still be found.
Mechanism

How It Works

The alternatives divide into three broad strategies: restrict which pairs interact, algebraically reorder the computation so the sequence dimension collapses, or abandon pairwise interaction for a recurrence with a learned state. A fourth strategy ignores asymptotics entirely and optimises how exact attention touches memory.

Sparsifying and linearising: Longformer (Beltagy et al., 2020) combines a sliding local window with a few global tokens; BigBird (Zaheer et al., 2020) adds random connections and proves the resulting sparse pattern retains universal approximation and Turing completeness. Linear attention takes a different route: Katharopoulos et al. (2020) observed that if the softmax is replaced by a feature map applied separately to queries and keys, associativity lets you compute the key-value summary once and reuse it, turning the cost linear in sequence length and revealing an exact duality with a recurrent network. Performer approximates the softmax kernel itself with random features, keeping closer to true attention behaviour.

Structured state spaces: S4 (Gu, Goel & Ré, 2022) models each channel as a continuous-time linear system discretised into a very long convolution, using a structured parameterisation of the state matrix so that a kernel spanning thousands of steps stays tractable and stable. Its results on the Long Range Arena benchmark — where transformers had struggled badly on the pathological long-dependency tasks — showed that principled recurrence could beat attention on raw long-range capability. Mamba (Gu & Dao, 2023) made the state transitions input-dependent, so the model can selectively remember or forget based on content. That breaks the convolution trick, and the paper's contribution is as much a hardware-aware parallel scan kernel that keeps state in fast on-chip memory as it is a modelling idea. Mamba-2 later recast selective SSMs as a form of structured matrix multiplication, exposing a duality with attention and letting the operation exploit tensor cores directly.

Hardware-aware exact attention: FlashAttention (Dao et al., 2022) changed the framing of the whole problem. It computes exact attention but tiles the computation so the full attention matrix is never written to high-bandwidth memory, using online softmax to accumulate results in SRAM. The asymptotic complexity is unchanged, yet wall-clock speedups were large enough that many approximate methods with better big-O were simply abandoned — a durable lesson that on modern accelerators memory traffic, not arithmetic, is usually the real cost.

Techniques

Key Techniques

Sparse & Windowed Attention

Local windows plus a handful of global or random tokens, as in Longformer and BigBird. Simple, well understood, and easy to bolt onto an existing transformer — but the pattern is fixed in advance and can miss dependencies it was not designed to carry.

Kernelised Linear Attention

Drop the softmax for a feature map so queries and keys can be reassociated, giving linear-time training and constant-memory recurrent inference. Performer instead approximates softmax with random features. Both typically lose some sharp retrieval ability.

Structured State Space Models

S4 and its descendants treat sequences as discretised linear dynamical systems with carefully structured state matrices, computed as long convolutions. Excellent on continuous signals, audio, and synthetic long-range tasks with stable, principled scaling.

Selective State Spaces

Mamba makes the recurrence input-dependent so the model gates what enters the state, closing much of the language-modelling gap with transformers. Mamba-2 reformulates this as structured matmuls to run efficiently on tensor-core hardware.

Recurrent-Attention Hybrids

RWKV replaces attention with a linear-attention-style recurrence that trains in parallel and runs as an RNN. Jamba interleaves Mamba blocks with occasional attention layers and mixture-of-experts, keeping precise recall where it is needed and constant memory elsewhere.

KV Cache Compression

Multi-query attention shares one key-value head across all query heads; grouped-query attention interpolates between MQA and full multi-head to recover quality. Latent attention compresses keys and values into a low-rank latent, shrinking the cache by a large factor.

Challenges

Challenges

🧠

Recall vs Efficiency

A fixed-size state cannot losslessly store an arbitrarily long context. Analyses of associative recall and verbatim copying consistently find pure recurrent models weaker than attention on exactly these tasks, and the gap appears to be structural rather than a training artefact.

📊

Misleading Benchmarks

Long Range Arena and perplexity at moderate length both flatter recurrent architectures. Retrieval-heavy long-context evaluations tell a different story, so architectural claims depend uncomfortably on which benchmark suite an author chooses to report.

🔧

Kernel & Tooling Debt

Attention benefits from years of highly tuned kernels across every framework and inference server. New primitives need bespoke scans and custom kernels, and often lose in wall-clock terms despite superior asymptotics until that engineering exists.

🔬

Ecosystem Transfer

Techniques built around attention — many interpretability tools, KV-cache prefix reuse, speculative decoding, positional extrapolation tricks — do not port cleanly to recurrent states, so adopting a new architecture means rebuilding surrounding infrastructure.

Literature

Key Papers & Resources

  • 📄
    Longformer: The Long-Document Transformer
    Beltagy, Peters & Cohan, 2020 — Combines sliding-window local attention with task-motivated global tokens, scaling transformers to thousands of tokens for document-level tasks.
  • 📄
    Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention
    Katharopoulos et al., 2020 — Shows that kernelised attention permits linear-time computation and an exact recurrent formulation for constant-memory autoregressive inference.
  • 📄
    Efficiently Modeling Long Sequences with Structured State Spaces (S4)
    Gu, Goel & Ré, 2022 — Introduces a structured state space layer that handles very long dependencies stably and set new results on Long Range Arena.
  • 📄
    Mamba: Linear-Time Sequence Modeling with Selective State Spaces
    Gu & Dao, 2023 — Adds input-dependent selectivity to state space models plus a hardware-aware parallel scan, reaching transformer-level language modelling with linear scaling.
  • 📄
    FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness
    Dao et al., 2022 — Tiles exact attention to avoid materialising the attention matrix in HBM, delivering large wall-clock gains and reframing efficiency as a memory-traffic problem.
Looking Ahead

Future Directions

  • Principled Hybrid Design: Moving from empirically tuned attention-to-SSM ratios toward a theory of how many precise-recall layers a task actually requires, and where in the stack they belong.
  • Expressive Bounded Memory: Richer state update rules — matrix-valued states, delta-rule and test-time-regression style updates, learned forgetting — that raise associative recall capacity without giving up constant per-token cost.
  • Hardware-Architecture Co-Design: Designing primitives alongside the accelerators that will run them, following FlashAttention's lesson that memory hierarchy and kernel design decide which asymptotic advantages ever materialise in practice.
  • Honest Long-Context Evaluation: Benchmarks that jointly measure retrieval accuracy, reasoning over dispersed evidence, and real throughput at length, so that architectural comparisons stop depending on the evaluation suite chosen.
